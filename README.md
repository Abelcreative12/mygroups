# Community Hub - WhatsApp Group Landing Page

A fast, responsive landing page bridging social media ad campaigns and official WhatsApp community groups.

## Features
- Direct routing to designated WhatsApp group invite links
- In-app browser handling with one-tap deep linking (intent URL) and clipboard auto-copy
- Clear anti-gambling disclaimers and community guidelines for advertising compliance
- Modern, accessible UI built with React, Vite, Tailwind CSS, and shadcn/ui

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
